What the automation does

Five steps, running 24/7 — so a cash buyer at 2 AM gets the same instant, polished response as one at 2 PM.

🏡

Capture

Every inquiry hits a webhook instantly — no more buyers waiting days for a callback while they browse competitors.

🧠

Qualify

A transparent rule-based engine scores buyer intent 0–100 from budget, timeline, financing, intent and message signals. No black box.

🗄️

Save

The lead lands in the CRM (Supabase) with its score, tier and full run history.

💬

Follow up

Hot buyers get an instant WhatsApp + email and a same-day call task. Warm and cold leads get their own lighter sequences.

⚡

Alert

Score 75+ triggers a WhatsApp alert so the agent can call within minutes — while the buyer is still hot.

Automation qualifies. Humans close.

Luxury buyers expect a personal touch — so this pipeline never pretends to be the agent. It handles the instant response, the qualification questions and the follow-up scheduling, then hands every hot buyer to a real human with full context. Your team spends its time closing, not chasing.

Honest breakdown: simulated vs. real

Simulated in this demo

  • • Webhook, scoring, CRM, messages, alerts — all in-browser
  • • Leads persist only in your browser (localStorage)
  • • No messages are actually sent anywhere

Real in production

  • • Same scoring rules run in an n8n Code node
  • • Supabase CRM, real WhatsApp + email sends
  • • Waits schedule Day 1 / Day 3 follow-ups for real
  • • Agent alert via WhatsApp Business API

This is a concept demo built to show what the automation looks like — not a client project, and no client names, testimonials or results are claimed anywhere.
